# People models

The men and women in `men/` and `women/` are from Quaternius's **Ultimate Modular Men Pack** and **Ultimate Modular Women Pack** (https://quaternius.com), released under **CC0 1.0** (public domain). No attribution is required; credited here with thanks.

Each file has four parts on one skeleton (Head, Body, Legs, Feet), so parts from different outfits of the same sex are mixed in `scripts/world/people.gd`. Animation is done in code (`scripts/world/person_rig.gd`).
